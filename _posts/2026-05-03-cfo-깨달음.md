## 서론: CFO의 위대한(?) 깨달음

Reddit r/LocalLLM에 올라온 글 하나가 200업보트를 넘겼다. 내용은 간단하다:

**"CFO가 계산해봤더니, AI 토큰 예산이 우리가 해고한 직원들 급여보다 높더라."**

읽으면서 웃었다. 그리고 곧 웃음이 멈췄다. 왜냐하면 나도 Claude API 달 결제액을 볼 때마다 비슷한 기분을 느끼니까. (진심으로, 지난달 내 API 비용이 내 위시리스트에 있는 AirPods Pro 가격을 넘었다. 나는 개발자고, 고객이 아닌데.)

이건 개인적인 문제가 아니다. 구조적인 모순이다.

## 골드러시의 삽 장사

골드러시 이야기 다들 알 거다. 1849년 캘리포니아. 금을 찾으러 온 사람들 대부분은 망했다. 진짜 돈을 번 건 삽 파는 사람들이었다.

2026년. AI 골드러시. 누가 삽을 파는가?

**Nvidia.**

- H100, B200, 그 다음은 뭐가 될지 모르겠지만 분명 더 비싸다
- API 제공사들 (OpenAI, Anthropic, Google)도 사실상 삽 장사 — 인프라를 가진 자가 이긴다
- 클라우드 회사들? 마찬가지. GPU 시간당 요금이 그들의 금광이다

기업들은 "AI로 효율화하자"며 직원을 해고하고, 그 빈자리를 API 호출로 채운다. 그런데 그 API 호출 1회당 N장의 GPU가 돌아가고, 그 GPU는 Nvidia에서 샀다. 결국 해고한 직원의 급여가 San Jose 본사로 흘러가는 구조다. (아름답다. 자본주의의 시 같다.)

## 토큰비 > 인건비의 역설

이게 핵심이다. 숫자를 생각해보자.

시니어 개발자 한 명의 연봉이 보통 1억~1.5억 원이라고 치자. 회사는 "AI로 대체하면 비용 절감!"이라며 해고한다. 그리고:

- GPT-4o 기반 에이전트가 코드 리뷰, 버그 수정, 테스트 작성을 돌게 한다
- 하루에 수만 건의 API 호출이 발생한다
- Claude, GPT, Gemini 왔다갔다하며 쓴다 (물론 각각 다른 구독과 사용료)
- 한 달 결제액을 보니... **직원 한 명 급여의 1.2~2배**

어?

물론 "AI는 24시간 일하니까"라는 반론이 있다. 맞다. AI는 야근 수당 안 받고 퇴사 안 한다. 하지만 AI가 작동하려면:

1. 프롬프트 엔지니어링을 해야 한다 → **사람이 함**
2. 결과물을 검증해야 한다 → **사람이 함**
3. 환각(hallucination)을 잡아야 한다 → **사람이 함**
4. 시스템을 유지보수해야 한다 → **사람이 함**

결국 사람을 해고해서 AI를 돌리는데, AI 비용이 더 비싸고, 그 위에 검증할 사람까지 필요하다. 이건 비용 절감이 아니라 비용 이전이다. 아니, 이전도 아니다. **증가**다. (이거 틀린 말 아니다. 실제로 이런 경우가 늘고 있다.)

## 순환경제의 딜레마

가장 철학적인 질문은 이거다:

> "고객의 직업을 자동화하면, 누가 네 제품을 사는가?"

생각해보라:

- SaaS 회사가 개발자를 해고한다
- 해고된 개발자는 다른 SaaS 구독을 취소한다
- 매출이 줄어든 SaaS 회사는 더 많은 사람을 해고한다
- 해고된 사람들은 더 많은 구독을 취소한다
- ...무한 루프

이건 경제학에서 "technological unemployment"라고 부르는 현상의 한 단계다. 역사적으로는 새 직업이 생겨서 해결됐지만, 이번엔 좀 다르다. AI가 대체하는 게 "직업" 단위가 아니라 "인지 노동" 자체니까.

물론 당장 내일 경제가 붕괴하진 않겠다. 사람들은 여전히 커피를 마시고 Netflix를 본다. 하지만 중산층 기술직이 줄어들면, 그 여파는 결국 모든 산업에 닿는다. AI 회사의 고객이 기업인데, 그 기업의 고객이 직장인인데, 그 직장인이 해고되면... 누가 AI를 쓰는 기업의 제품을 사는가?

순환경제. 원래는 재활용 뜻이었는데, 지금은 "돈이 순환하지 않는 경제"가 됐다. (이건 좀 웃기지 않나. 나만 웃김?)

## 개발자는 어떻게 준비할까

그래서 우리는 뭘 해야 하나.

**1. 비용 구조를 이해하라.** API 비용이 얼마인지, 토큰 단가가 어떻게 책정되는지 알아야 한다. 이건 선택이 아니라 생존 기술이다. 모르면 진다.

**2. 로컬 모델을 알아두라.** Llama, Mistral, Qwen 같은 오픈 모델이 왜 중요한지 이제 감이 온다. API 비용이 감당 안 되면, 로컬로 돌릴 줄 알아야 한다. r/LocalLLM이 뜨는 이유가 있다.

**3. AI를 "대체"가 아니라 "도구"로 써라.** AI가 내 일을 대체하게 두지 말고, 내가 AI를 쓰는 사람이 되자. 이 차이가 크다. (물론 쉽지 않다. 나도 매일 고민함.)

**4. 비즈니스 감각을 길러라.** 기술만 좋으면 되는 시대는 지났다. "이 AI 도입이 실제로 비용을 절감하는가?"를 스스로 물을 수 있어야 한다. 대답이 "모르겠다"면, 더 알아봐야 한다.

## 정리

CFO의 깨달음은 우리 모두의 깨달음이다. AI는 강력한 도구다. 하지만 도구에는 항상 비용이 따르고, 그 비용이 기대보다 클 수 있다.

해고한 직원 급여보다 토큰비가 더 나온다면, 뭐가 절약된 건가?

아마도 Nvidia 주식만 올랐을 것이다.

나도 API 비용 좀 줄여야겠다. 오늘부터 로컬 모델 돌려야지. (이번 주만 일곱 번째 다짐이다.)
