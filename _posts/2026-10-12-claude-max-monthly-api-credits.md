매달 200달러를 거저 준다는 소식이 [r/ClaudeCode에](https://www.reddit.com/r/ClaudeCode/comments/1x31yts/claude_max_20x_now_get_200_in_api_credits/) 올라왔다. Anthropic이 Max 20x 구독자에게 매달 API 크레딧 200달러를 지급하기 시작했다는 것. Max 5x 구독자는 100달러를 받는다. 구독료와 별개로 떨어지는 돈이니, 처음 듣는 순간은 반신반의할 수밖에 없다. 어디에 쓸 수 있는 돈인지, 조건은 어떤지부터 따져보게 된다.

## 매달 갱신되지만, 쌓이지는 않는다

정리하면 이렇다. Claude 콘솔의 조직(organization)을 구독 계정과 연결하면 크레딧이 활성화된다. 매 결제 주기마다 200달러가 채워지고, 못 쓴 몫은 다음 달로 넘어가지 않는다. 사용처는 Claude API, Agent SDK, Managed Agents, Playground 네 곳. 일반 Claude Code 세션이나 Claude 앱 사용량 확장에는 쓸 수 없다.

글을 올린 u/onepunchcode는 스타트업 대상 SaaS를 만들어 파는 개발자다. 이 돈이 어디에 쓸모 있는지 가장 잘 보여주는 사례다. 잠재 고객이 구매 전에 AI 기능을 직접 만져보게 두려면 API 호출 비용이 계속 나간다. 규모가 있는 데모 사이트라면 이게 꽤 아픈 지출이다. 매달 200달러면 이런 '구경시켜 주는 비용'을 상당 부분 덜 수 있다는 계산이 나온다. 내 작업 흐름이 아니라, 팔리는 제품 쪽에 보태지는 돈이라는 얘기다.

## 조건을 읽으면 의도가 보인다

이상한 부분부터 눈에 걸린다. 왜 Claude Code에는 못 쓰게 막아둘까. 구독자 입장에선 가장 쓰고 싶은 곳이 거기일 텐데.

짚어보면 답이 보인다. 구독의 본래 용도인 에이전트 코딩은 이미 구독료가 커버한다. 크레딧을 거기에도 열어두면 결국 구독료를 아끼는 수단으로 소모될 뿐이다. Anthropic이 원하는 흐름은 그 반대다. 개발은 구독으로 하고, 그 결과물은 API 위에 올려 밖으로 내보내라. Agent SDK와 Managed Agents, Playground만 허용된 것도 같은 방향이다. 전부 무언가를 만들어 돌리는 자리들이다.

이월이 안 되는 것도 같은 맥락이다. 쌓아둘 수 없는 크레딧은 저금통이 아니라 쿠폰에 가깝다. 이번 달 안에 뭔가 돌려보게 만드는 설계다. 데모 하나 더 띄우고, 실험 하나 더 붙이고. 그러다 월 200달러를 넘어서는 순간, 자연스럽게 과금 API 고객이 된다. 거저 준 돈의 상당수는 이 경로로 되돌아온다.

## 같은 날, 파키스탄의 작은 스타트업도

우연의 일치라기엔 타이밍이 좋다. 같은 날 [다른 글이](https://www.reddit.com/r/ClaudeCode/comments/1x2zqrq/anthropic_just_gave_us_1000_in_api_credits_up_to/) 하나 더 올라왔다. 파키스탄의 부트스트랩 스타트업이 Claude for Startups 심사를 통과해 API 크레딧 1,000달러를 받았고, Team 요금 할인(월 최대 625달러, 12개월)까지 더해 8,500달러 가까운 지원을 확보했다는 이야기다. 글쓴이의 표현을 빌리면, 달러를 세며 쓰던 작은 팀이 실험하고 부수고 고칠 여유를 얻었다는 것.

개인 구독자의 월 200달러와 스타트업의 1,000달러 + 팀 할인. 따로 보면 이벤트성 혜택이지만, 나란히 놓으면 하나의 깔때기로 읽힌다. 혼자 쓰던 개발자가 구독을 올리고, 크레딧으로 뭔가를 만들고, 팀을 꾸리고, 회사가 되는 경로 전체에 보조금이 붙어 있다. 상류부터 하류까지 지출을 줄여주는 구조다.

## 왜 주목할까

지금까지 구독과 API는 사실상 다른 경제였다. 구독은 정액제 워크플로 도구였고, API는 토큰 단위로 계산하는 인프라 비용이었다. 이 둘을 한 계정으로 묶고 한쪽에 월 200달러를 흘려보내는 순간, 경계의 성격이 달라진다. 구독이 개발 환경을 넘어 배포 환경까지 아우르는 입구 노릇을 시작한 것.

에이전트로 뭔가를 만드는 입장에서는 지출 지도를 다시 그리게 된다. 예전엔 취미로 돌리는 데모조차 호출량이 늘면 부담이었다. 이제는 월 일정액까지는 공짜처럼 굴러간다. 만들어서 보여주는 비용이 낮아지면 만드는 단위도 작아진다. 던져보는 사이드 프로젝트가 하나 더 늘어나는 식으로.

물론 계산은 직접 해봐야 한다. 200달러면 Claude API 기준으로 제법 되는 호출량이지만, 데모에 붙인 기능의 토큰 소모를 과소평가하면 트래픽 파도 한두 번으로 증발한다. 무료 한도 안에서만 설계하는 습관이 오히려 새로 생기는 셈이다.

## 정리

매달 200달러. 적지 않은 돈이고 조건도 분명하다. 못 쓰면 사라지고, Claude Code 세션에는 못 쓴다. 그런데 이 조건들이 모순 없이 한 방향을 가리킨다는 점이 이 소식의 본질에 가깝다. 개발은 구독으로, 결과물은 API로. 그 사이의 벽을 Anthropic이 스스로 허물고 있는 중이다. 구독료를 내는 쪽에서 이 돈을 어떻게 소화할지는 이제 각자의 선택이다.
