자고 일어났더니 앤트로픽이 매달 200달러를 거저 준다고 해서 스팸인 줄 알았다.

매달 통장에 200달러(약 28만 원) 상당의 크레딧을 묻지도 따지지도 않고 꽂아준다는 믿기 힘든 소식이 [r/ClaudeCode에](https://www.reddit.com/r/ClaudeCode/comments/1x31yts/claude_max_20x_now_get_200_in_api_credits/) 올라왔다. Anthropic이 Claude Max 20x 플랜 구독자들에게 매달 API 크레딧 200달러를 무상 지급하기 시작했다는 것. 심지어 Max 5x 구독자에게도 매달 100달러가 떨어진다. 구독료 외에 공짜 보너스로 떨어지는 돈이니, 처음 접했을 땐 "세상에 공짜 점심이 어딨어, 뭔가 낚시 아니야?" 하고 의심부터 들었다. 어디에 쓸 수 있고 조건은 뭔지 꼼꼼히 뜯어봤다.

## 매달 충전되지만, 이월은 안 된다

세부 조건을 까보면 이렇다. Claude 웹 콘솔의 조직(Organization) 계정을 본인의 Max 구독 계정과 연동하면 크레딧이 활성화된다. 매달 결제 주기마다 200달러가 꼬박꼬박 리필되지만, 이번 달에 다 못 쓴 잔액은 다음 달로 이월되지 않고 칼같이 소멸한다.

사용처도 철저히 제한되어 있다. 사용 가능한 곳은 Claude API, Agent SDK, Managed Agents, 그리고 Playground 네 군데뿐이다. 우리가 매일 쓰는 일반 Claude Code CLI 세션이나 Claude 웹 채팅창의 사용량 한도를 늘리는 데는 1원도 쓸 수 없다.

이 글을 올린 u/onepunchcode는 스타트업용 B2B SaaS를 만들어 파는 1인 개발자다. 이 크레딧이 누구에게 가장 꿀맛 같은지 정확히 보여준다. 잠재 고객들이 구매 결정을 내리기 전에 웹사이트에서 AI 기능을 무료로 체험해보게 하려면 백단에서 API 호출 비용이 계속 새어 나간다. 트래픽이 좀 몰리는 데모 사이트라면 매달 나가는 API 비용이 꽤 쓰린 지출이다. 그런데 매달 200달러를 공짜로 대주면 이런 '고객 구경시켜 주는 비용'을 완전히 공짜로 퉁칠 수 있다. 개인 코딩 노동이 아니라, 실제 돈을 벌어오는 제품 쪽에 힘을 실어주는 지원금인 셈이다.

## 조건을 뜯어보면 앤트로픽의 큰 그림이 보인다

가장 의아했던 부분은 "왜 개발자들이 제일 많이 쓰는 Claude Code 세션에는 못 쓰게 틀어막았을까?"였다.

머리를 굴려보니 앤트로픽의 영악한 속내가 훤히 보인다. 구독자들이 자기 코딩 작업하는 건 이미 매달 내는 정액제 구독료로 충분히 커버치고 있다. 만약 여기에 200달러 크레딧까지 쓸 수 있게 열어주면, 사람들은 구독 등급을 낮추고 공짜 크레딧으로 꿀만 빨다가 나갈 게 뻔하다.

Anthropic이 원하는 진짜 그림은 정반대다. "개발과 삽질은 Max 구독으로 마음껏 치고, 그렇게 완성된 상용 제품과 에이전트는 API 위에 올려서 세상 밖으로 출시해라!"라는 강력한 메시지다. Agent SDK와 Managed Agents만 콕 집어 허용한 것도 같은 맥락이다. 전부 무언가를 만들어서 엔드 유저에게 서빙하는 자리들이다.

이월을 막아둔 것도 기가 막힌 심리전이다. 저축이 안 되는 쿠폰은 사람을 안달 나게 만든다. "이번 달에 안 쓰면 200달러 그냥 날아가는데 뭐라도 하나 띄워볼까?" 하고 새로운 사이드 프로젝트 데모를 만들고, 새로운 AI 기능을 붙이게 유도한다. 그러다 사용자가 늘어나 월 200달러 무료 한도를 뚫는 순간? 자연스럽게 앤트로픽의 충성스러운 유료 API 고객으로 전환된다. 거저 준 돈의 몇 배가 결국 앤트로픽 금고로 되돌아오는 영리한 깔때기 설계다.

## 같은 날, 파키스탄의 작은 스타트업에도 터진 대박

타이밍도 절묘하다. 같은 날 [또 다른 글](https://www.reddit.com/r/ClaudeCode/comments/1x2zqrq/anthropic_just_gave_us_1000_in_api_credits_up_to/)이 레딧을 달궜다. 파키스탄의 작은 부트스트랩 스타트업이 Claude for Startups 프로그램에 선정되어 초기 API 크레딧 1,000달러에 더해 향후 1년간 팀 플랜 요금 할인까지 묶어 총 8,500달러(약 1,200만 원) 상당의 지원을 따냈다는 소식이었다. 한 푼이 아쉬워 토큰을 세어가며 쓰던 가난한 팀이 비로소 마음 놓고 프로덕트를 테스트할 날개를 얻었다는 감격 어린 후기였다.

개인 개발자에게 주는 월 200달러와 스타트업에게 쥐여주는 1,000달러 지원금. 따로 보면 단발성 이벤트 같지만, 하나로 이어보면 거대한 '개발자 락인(Lock-in)' 생태계가 보인다. 혼자 코딩하던 개발자가 Max 구독을 결제하고, 매달 떨어지는 크레딧으로 사이드 프로젝트를 론칭하고, 팀을 꾸려 스타트업으로 도약하는 전 과정에 앤트로픽이 마중물을 부어주고 있다.

## 왜 여기에 주목해야 할까

그동안 '구독(Subscription)'과 'API'는 사실상 다른 세상이었다. 구독은 개발자 개인의 생산성을 위한 정액제 도구였고, API는 서버에 물려 호출 건당 결제하는 인프라 비용이었다.

그런데 이 둘을 하나의 계정으로 묶고 매달 200달러의 유동성을 흘려보내면서 그 경계가 무너져 내렸다. 정액제 구독이 단순히 코딩 도구를 넘어, 프로덕트를 세상에 배포하는 인프라의 관문 역할까지 겸하기 시작한 것이다.

사이드 프로젝트를 취미로 굴리는 1인 개발자 입장에서는 지출 설계도가 완전히 바뀐다. 예전엔 데모 사이트 하나 띄우려 해도 API 호출 폭탄 맞을까 봐 무서워서 벌벌 떨었는데, 이제는 월 200달러 안쪽이라면 거의 공짜로 서비스를 굴릴 수 있다. 실패 비용이 낮아지니 "주말에 심심한데 토이 프로젝트 하나 더 던져볼까?" 하는 실행력이 폭발하게 된다.

## 정리

매달 200달러. 결코 적은 돈이 아니다. 조건은 단호하다. 못 쓰면 사라지고, Claude Code 코딩에는 못 쓴다.

하지만 이 제약 조건들이 가리키는 방향은 선명하다. 개발은 구독으로 신나게 치고, 결과물은 API로 배포해라. 그 사이의 거대한 벽을 앤트로픽이 스스로 허물고 있다. 밥상은 푸짐하게 차려졌으니, 매달 떨어지는 200달러를 어떻게 맛있게 요리해 먹을지는 이제 개발자 각자의 몫이다!
