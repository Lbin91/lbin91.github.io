구독료 앞에서는 다들 계산기가 빨라진다(나 역시 마찬가지다).

Claude Code 레딧 커뮤니티에 글 하나가 올라왔는데 순식간에 난리가 났다. 제목부터 도발적이다. "OK BOYS IT'S OVER.. No Subscription required." Claude Code 정식 구독 없이도 Claude 모델을 우회해서 쓸 수 있다는 내용이었는데, 2,000개가 넘는 업보트가 찍혔다.

처음엔 흔한 어그로인 줄 알고 낄낄대며 들어갔던 개발자들이 "어? 이거 진짜 되네?" 하면서 눈이 뒤집혔다.

## 무슨 일이 일어났나

발단은 스크린샷 한 장이었다. Claude Code의 Max 플랜 정식 구독 없이도 Claude 모델에 접근할 수 있는 우회 경로를 보여주는 내용이었고, 작성자는 "농담 아니라 진짜 된다"고 못 박았다. 이후 유저들이 직접 따라 해보더니 실제로 뚫린다는 인증 댓글이 줄줄이 달렸다.

사실 우회 방법 자체보다 타이밍이 기가 막혔다. 커뮤니티 민심이 이미 바닥을 치고 있던 시점이었기 때문이다. 가격은 올랐는데 품질 저하 논란은 계속 터지고, 세션 제한은 숨 막힐 정도로 빡빡해졌다. 이런 상황에서 "구독 없이 쓸 수 있다"는 글이 터졌으니 불길에 기름을 부은 격이다.

Anthropic 입장에선 속이 쓰릴 수밖에 없는 장면이다. 유저들이 제품이 좋아서 모이는 게 아니라, 어떻게든 비싼 구독료를 회피할 구멍을 찾느라 혈안이 되어 있으니까.

## 댓글은 자연스럽게 오픈소스 대안으로 흘렀다

가장 많은 추천을 받은 댓글(131↑)은 OpenClaw와 물려 쓰라는 제안이었다. OpenClaw는 여러 LLM API를 한곳에서 주무르는 오픈소스 도구인데, 커뮤니티에선 이미 무료 LLM API 목록을 대대적으로 공유하며 축제 분위기였다. Cohere, Gemini, Ollama 무료 티어가 잇따라 붙으면서 "구독 없이 에이전트 코딩하기"가 점차 가시권에 들어오고 있다.

Amazon Rufus도 비슷한 방식으로 돌아간다는 분석이 나왔다. 빅테크들이 자기 플랫폼 서비스에 LLM을 기본 탑재하는 흐름이 거세질수록, 월 $100~200씩 받아먹는 독립 구독 모델은 점점 코너에 몰릴 거라는 해석이다.

물론 아직은 "오 이거 되네?" 수준의 해프닝에 가깝다. 당장 Claude Code 유료 구독이 와르르 무너지거나 시장이 끝장난다는 뜻은 아니다. 하지만 개발자들이 비용의 틈새를 얼마나 집요하고 빠르게 파고드는지 보면 살짝 소름이 돋는다.

## 왜 하필 지금 이렇게 폭발했을까

단순한 팁 공유 글이었다면 2,000표 넘게 몰릴 리가 없다. 사람들의 가슴속에 쌓여 있던 구독료 불만이 이 글을 기폭제 삼아 터져 나온 거다.

Opus 4.7이 나오면서 토큰 단가가 무려 65%나 뛰었다. Max 구독자들 사이에서도 "이틀 만에 주간 한도 39%가 날아갔다"는 비명이 쏟아졌다. 커뮤니티에 돌아다니는 비교표(GLM-5.1 월 $31 vs Opus 4.7 월 $261)를 보고 있으면 배신감이 드는 게 당연하다.

게다가 대안 진영의 체급이 올라온 것도 한몫했다. 불과 몇 달 전만 해도 "Claude Code 대안"이라고 하면 어딘가 미심쩍은 광고글 같았는데, 지금은 GLM-5.1, Qwen 3.5, MiniMax 같은 가성비 모델로 실제로 갈아타는 유저들이 쏟아져 나온다.

Codex, 로컬 LLM, 무료 API를 상황에 따라 스위칭하며 쓰는 방식도 이제는 기본 상식이 됐다. 예전엔 툴 하나에 뼈를 묻는 게 자연스러웠다면, 요즘은 작업 성격에 맞춰 도구를 갈아 끼우는 게 훨씬 스마트하다.

## 앞으로의 흐름

"구독 끝났다"는 말을 문자 그대로 믿는 건 순진하다. Claude Code의 편리한 완성도와 안정성, 공식 지원은 여전히 돈을 지불할 가치가 있다.

하지만 이번 소동이 남긴 메시지는 명확하다. 개발자들은 가격표가 선을 넘었다고 느끼는 순간, 언제든 뒤도 안 돌아보고 대안을 찾아 떠난다. 그리고 지금은 갈아탈 선택지가 너무나 많다.

GLM-5.1이 월 $31 수준으로 Opus 4.7의 10분의 1도 안 되는 비용을 자랑하고, OpenClaw 같은 오픈소스 도구들이 진입장벽을 허물고 있는 시대다. 한 기업의 독점 생태계에 갇혀 지갑을 털리는 시대는 끝났다.

나 역시 구독 결제일 알림이 뜰 때마다 "이게 진짜 맞나..." 싶어서 흠칫한다(통장이 비명을 지른다). 이제는 고민만 할 게 아니라 실제 오픈소스 대안들을 하나씩 내 작업 환경에 물려봐야겠다. 지갑이 먼저 비상벨을 울리고 있다.
