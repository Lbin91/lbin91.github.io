구독료 앞에서는 다들 계산기가 빨라진다.

Claude Code 커뮤니티에서 게시물 하나가 크게 올라왔다. 제목은 "OK BOYS IT'S OVER.. No Subscription required." Claude Code 구독 없이도 Claude 모델을 쓸 수 있다는 내용이었고, 2,011표가 몰렸다.

제목만 보면 그냥 커뮤니티식 과장처럼 보이는데, 댓글 분위기는 생각보다 진지했다. 사람들이 웃으면서 들어왔다가, "근데 이거 진짜 되네?" 쪽으로 넘어간 느낌이다.

## 무슨 일이 일어났나

스크린샷 한 장이 전부였다. Claude Code의 정식 구독(Max 플랜) 없이도 Claude 모델에 접근할 수 있는 우회 방법을 보여주는 내용이었고, 작성자는 "농담 아니라 진짜 된다"는 식으로 덧붙였다. 이후 사람들이 직접 시도해봤고, 실제로 된다는 반응이 붙기 시작했다.

사실 방법 자체보다 타이밍이 더 컸다. 커뮤니티 분위기가 이미 좋지 않았다. 비용은 올랐는데 품질 논란도 있고, 사용량 제한은 더 빡빡해졌고. 그런 상황에서 "구독 없이도 쓸 수 있다"는 글이 올라오니 반응이 커질 수밖에 없었다.

회사 입장에선 꽤 피곤한 장면이다. 사용자가 제품을 좋아해서가 아니라, 비용을 피할 방법을 찾느라 모여들고 있으니까.

## 댓글은 자연스럽게 대안 이야기로 흘렀다

추천을 가장 많이 받은 댓글(131↑)은 OpenClaw와 연결하라는 제안이었다. OpenClaw는 여러 LLM API를 한 곳에서 관리하는 오픈소스 프로젝트인데, 관련 커뮤니티에서는 이미 무료 LLM API 목록을 대규모로 업데이트하면서 화제였다. Cohere, Gemini, Ollama 무료 티어가 잇따라 추가되면서 "구독 없이 AI 코딩"이 점점 현실이 되어가고 있다.

Amazon Rufus도 비슷한 방식으로 동작한다는 얘기가 나왔다. 빅테크들이 자기 서비스에 LLM을 끼워 넣는 패턴이 늘어나면서, 전용 구독 모델이 갈수록 흔들리는 것 아니냐는 해석도 붙었다.

물론 아직은 "이거 되네?" 수준의 소동에 가깝다. 당장 Claude Code 구독이 무너진다거나, 유료 모델 시장이 끝난다는 이야기는 아니다. 그래도 개발자들이 이런 틈을 얼마나 빠르게 찾아내는지 보면 좀 무섭다.

## 왜 하필 지금 이렇게 반응했을까

단순한 팁 공유였으면 2,011표까지는 안 갔을 거다. 사람들이 이미 불만을 쌓아두고 있었고, 이 게시물이 그 불만을 건드렸다.

Opus 4.7이 나오면서 토큰당 비용이 65%나 올랐다. Max 구독자 중에는 "이틀 만에 주간 한도 39%를 썼다"며 불만을 터뜨린 사람도 있었다. 커뮤니티에서 공유된 비교표(glm-5.1 $31/월 vs Opus 4.7 $261/월)를 보면 불만이 이해가 된다.

그리고 대안이 어느 정도 준비된 것도 크다. 몇 달 전만 해도 "Claude Code 대안" 얘기하면 약간 수상한 홍보글처럼 보였는데, 지금은 GLM-5.1, Qwen 3.5, Minimax 같은 저비용 모델로 실제로 갈아타는 사람이 늘고 있다.

Codex, 로컬 모델, 무료 API를 상황에 따라 섞어 쓰는 방식도 이제 그렇게 특이하지 않다. 예전엔 모델 하나 정해서 쭉 쓰는 게 자연스러웠는데, 요즘은 작업마다 도구를 바꿔 끼우는 쪽이 더 현실적이다.

## 앞으로

"구독 끝났다"는 말 그대로 받아들이면 당연히 과장이다. Claude Code 구독이 하루아침에 의미 없어지는 일은 없을 거다. 좋은 모델, 안정적인 도구, 공식 지원은 여전히 돈을 낼 이유가 된다.

다만 이번 반응이 보여준 건 분명하다. 개발자들은 가격이 부담스럽다고 느끼는 순간, 바로 대안을 찾기 시작한다. 그리고 지금은 그 대안이 예전보다 훨씬 많다.

glm-5.1이 월 $31로 Opus 4.7의 12분의 1 비용이고, OpenClaw 같은 플랫폼이 진입장벽을 낮추고 있다면 이야기가 달라진다. AI 코딩 도구 시장은 한 회사만 믿고 가는 시대에서, 여러 선택지를 섞어 쓰는 시대로 넘어가는 중이다.

나도 구독 하나 더 늘릴 때마다 "이게 맞나..." 싶어진다. 이제는 고민만 할 게 아니라 실제 대안들을 한 번씩 돌려봐야겠다. 지갑이 먼저 신호를 보내고 있다.
