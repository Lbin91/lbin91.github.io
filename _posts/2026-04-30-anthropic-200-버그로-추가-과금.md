자기네 CLI 버그로 200달러가 눈먼 돈처럼 결제됐는데 환불을 못 해주겠단다(이게 날강도가 아니면 뭘까).

Claude Code 버그로 200달러를 억울하게 털린 개발자가 Anthropic 고객센터에 항의했다가 "환불 불가" 답변을 받은 사연이 r/claudecode를 발칵 뒤집어놓았다. GitHub 이슈로 공론화되면서 AI 도구의 불투명한 과금 시스템에 대한 비판이 거세게 일고 있다.

## 무슨 버그였나

GitHub 이슈 내용을 뜯어보면, push 옵션이나 설정 파일 파싱 로직에서 에러가 나면서 백그라운드에서 무한 루프 수준으로 토큰을 집어삼킨 것으로 드러났다. 사용자가 코딩을 폭풍처럼 한 것도 아닌데 토큰 카운터가 미친 듯이 돌아가며 200달러가 긁혔다.

명백한 클라이언트 도구의 결함인데도 Anthropic 측은 규정을 들이밀며 환불을 딱 잘라 거절했다. 세계 최고의 AI를 만든다는 회사가 정작 기본적인 결제 안전장치와 고객 지원은 바닥 수준이라는 비판이 쏟아졌다.

## 레딧의 조언: "당장 카드사에 차지백(Chargeback) 때려라"

가장 많은 추천을 받은 댓글은 지극히 현실적이었다. "고객센터랑 입씨름하지 말고 신용카드사에 부정 결제/서비스 결함으로 차지백(Chargeback)을 신청하라"는 조언이다.

논란이 일파만파 번지고 X(트위터)와 커뮤니티에서 불매 여론이 일자, 그제서야 Anthropic 측이 마지못해 환불 처리에 나섰다는 후속 소식이 전해졌다. 공론화가 안 됐으면 그대로 꿀꺽 삼켰을 거라는 뜻이다.

## 과금 안전장치가 시급하다

이 사건은 사용량 기반 종량제 과금의 가장 어두운 단면을 보여준다.
- 세션별 실시간 토큰 지출을 직관적으로 확인할 수 있는 대시보드
- "하루 지출 10달러 초과 시 즉시 프로세스 강제 종료" 같은 하드 리밋(Hard Limit)
- 비정상적인 무한 호출 감지 및 자동 환불 시스템

이런 최소한의 안전벨트도 없이 유저 신용카드를 물려놓고 에이전트를 돌리라는 건 너무 무책임하다. 한순간의 버그로 내 통장이 털릴 수 있다면 어떤 개발자가 안심하고 터미널을 맡기겠는가.
