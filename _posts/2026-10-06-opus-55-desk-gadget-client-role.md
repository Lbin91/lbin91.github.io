책상 위에 있는 작은 모니터를 멍하니 보다가 '내가 도대체 뭘 만든 거지?' 싶었다.

r/ClaudeCode에 올라온 글 하나가 커뮤니티를 제대로 뒤흔들었다. 제목부터 비범하다. "새 Claude Code mods 기능을 시험해 보려고 했을 뿐인데, 내가 손댄 적도 없고 주문한 적도 없는 하드웨어 완성품이 지금 내 책상 위에 놓여 있다." mods는 Claude Code에 들어온 일종의 확장 플러그인 기능인데, 작성자는 이걸 도구를 바꾸는 대신 내부 데이터를 밖으로 뽑아내는 리버스 엔지니어링 용도로 썼다. 30분이면 끝날 가벼운 주말 장난감 프로젝트라고 생각했다고 한다.

처음 아이디어는 소박했다. Claude Code의 실시간 구독 사용량과 컨텍스트 잔여량 데이터를 외부로 쏴서, 책상 위 USB 소형 보드 디스플레이에 게이지로 띄우는 것.

```
Claude Code ─ mods ─▶ 사용량 / 컨텍스트 데이터
                          │ USB 케이블
                          ▼
                  ESP32 소형 디스플레이
                  (케이스와 스탠드는 3D 프린팅)
```

## 코드는 기본이고, 3D CAD 설계까지 끝냈다

프로젝트에 들어간 모든 소스코드는 Claude가 단 한 줄의 사람 손도 안 빌리고 혼자서 다 짰다. Claude Code mod 스크립트, ESP32 펌웨어 C++ 코드, 디스플레이 화면을 예쁘게 그려주는 UI 렌더링 코드까지. 작성자가 한 일은 "나 이런 거 만들고 싶어"라고 말하고, 화면에 뜬 결과를 보고 "좋아, 진행해"라고 승인 버튼을 누른 클라이언트 역할이 전부였다.

진짜 소름 돋는 충격은 다음 단계에서 터졌다. 디스플레이 부품 제조사의 데이터시트 치수 도면(PDF)을 Claude에게 넘겼더니, 녀석이 FreeCAD를 백그라운드에서 직접 구동해서 디스플레이를 딱 감싸는 전용 케이스와 스탠드 3D 모델링 파일을 몇 분 만에 뚝딱 뽑아낸 것이다. 작성자가 그 STL 파일을 3D 프린터로 전송해서 출력한 뒤 부품을 끼워봤더니, 첫 시도만에 자로 잰 듯이 완벽하게 들어맞았다. 공차(Tolerance)를 사람이 손으로 수정한 적도 없는데, 나사 구멍과 부품 체결 부위가 한 치의 오차도 없이 맞물렸다.

소프트웨어 엔지니어, 임베디드 펌웨어 개발자, 하드웨어 기구 설계자... 보통은 최소 세 명이 모여서 몇 주 동안 회의하고 맞춰봐야 할 일이다. 이걸 AI 에이전트 하나가 단 한 번의 대화 세션에서 수작업 제로로 끝내버렸다(이러다 진짜 개발자 밥줄 다 끊기는 거 아닌가 하는 서늘함이 스친다).

## 불과 몇 주 사이에 일어난 패러다임 시프트

물론 흥분을 가라앉히고 냉정하게 따져볼 구석은 있다. 책상 위에 올려두는 소형 장난감 가젯이지 수백만 명이 쓰는 미션 크리티컬 프로덕션 시스템은 아니며, 사람의 코드 리뷰가 이제 완전히 필요 없어졌다는 뜻도 아니다. 작성자 본인도 이 점을 분명히 짚었다.

하지만 핵심은 속도의 변화다. 똑같은 프로젝트를 불과 반년 전에 시도했다면 어땠을까? 매 단계마다 사람이 달라붙어서 에러 로그 복붙해주고, 프롬프트 깎아주고, CAD 파일 깨진 거 수동으로 버텍스 수정하느라 온종일 'AI 베이비시팅'을 하고 있었을 것이다. 하지만 지금은 아니다. 그리고 이 극적인 도약이 몇 년이 아니라 최근 몇 주 사이에 Opus 5.5가 나오면서 터져 나왔다는 사실이 무섭다. 사용자가 Opus 5.5를 "야수(beast)"라고 부른 데는 다 이유가 있다.

주변 생태계의 흐름도 흥미롭다. 같은 날 r/ClaudeCode에는 에이전트가 어떤 파일을 읽고 고치고 있는지 실시간으로 모니터링해 주는 전용 터미널 UI인 GhosttyEXTREME 이야기도 화제가 됐다. AI가 알아서 다 하는 자율성의 시대가 열릴수록, 역설적으로 녀석이 무슨 짓을 벌이고 있는지 투명하게 감시하는 '관측 도구'의 중요성이 함께 커지는 셈이다.

## 왜 여기에 주목해야 할까

이 사례는 "AI가 코딩을 제법 잘한다"는 수준의 흔한 이야기를 아득히 넘어섰다. 소프트웨어 코드에서 임베디드 펌웨어로, 다시 물리적인 3차원 기구 설계와 실물 제작으로 이어지는 엔지니어링 전체 사슬을 단 하나의 프롬프트 세션으로 관통했다는 점이 핵심이다. 파이프라인의 끝에서 나온 결과물은 화면 속 픽셀이 아니라, 손으로 만질 수 있는 실물 하드웨어다.

여기서 인간 개발자의 역할도 근본적으로 바뀐다. 키보드를 두들겨 코드를 생산하는 '제작자'에서, 무엇을 만들지 방향을 정의하고 품질을 컨펌하는 '프로덕트 오너'에 가까워졌다.

작성자가 남긴 마지막 문장이 머릿속을 맴돈다. "이 도구를 매일 손에 쥐고 쓰는 개발자들조차 지금 세상이 어디까지 바뀌었는지 따라가기 벅찬데, 아직도 텍스트 챗봇 수준으로 생각하는 사람들은 얼마나 거대한 격차 속에 살고 있는 걸까."

작은 플라스틱 디스플레이 하나가 책상에 놓였을 뿐인데, 지금 우리가 어떤 시대를 통과하고 있는지 가장 직관적으로 보여준다. 몇 달 뒤엔 이런 자율 하드웨어 제작조차 너무 흔해서 아무도 신기해하지 않을지도 모르겠다. 그게 요즘 AI 발전의 무서운 속도다.
