오픈소스 판의 전설적인 인물이자 GitHub 초기 유저 1299번인 미첼 하시모토(Mitchell Hashimoto)가 기어이 깃허브를 떠났다.

"GitHub는 더 이상 진지한 작업을 위한 장소가 아니다."

Vagrant, Terraform을 만들고 현재는 GPU 가속 터미널 에뮬레이터 Ghostty를 이끄는 그가 던진 선언은 개발자 생태계에 묵직한 충격을 던졌다. 2008년 가을 깃허브 서비스 초창기부터 거의 매일 커밋을 찍어오던 산증인이 작별을 고한 거다.

## 왜 떠나는가?

Hashimoto가 Ghostty 프로젝트의 저장소를 GitHub에서 다른 협업 플랫폼으로 옮기기로 결정한 이유는 감정적인 투정이 아니다.

첫째는 **AI 스팸과 봇 노이즈의 범람**이다. 이슈 트래커와 PR 창이 영혼 없는 LLM 요약과 AI 자동 생성 스팸으로 뒤덮이면서, 진짜 개발자들 사이의 깊이 있는 기술 토론이 불가능한 지경에 이르렀다.

둘째는 **제품 혁신의 정체**다. 마이크로소프트에 인수된 이후 GitHub는 엔터프라이즈 기능과 코파일럿 판매에만 열을 올릴 뿐, 정작 개발자들이 매일 쓰는 이슈 관리, 코드 리뷰, 알림 시스템의 본질적인 사용성은 수년째 방치됐다.

## 마이크로소프트 체제의 깃허브가 잃어버린 것

GitHub는 한때 전 세계 해커들의 놀이터이자 성지였다. 하지만 지금의 GitHub는 대기업의 분기 실적을 맞추기 위한 거대한 세일즈 머신에 가깝다.

코파일럿 홍보 배너는 점점 커지는데, 정작 개발자들의 피로도를 줄여줄 모더레이션 도구는 턱없이 부족하다. 오픈소스 메인테이너들이 AI가 쏟아내는 쓰레기 이슈를 거르느라 번아웃에 빠지는 동안, 플랫폼은 아무런 방패막이가 되어주지 못했다.

## 정리

Hashimoto의 탈출은 단순한 한 거물의 이직이 아니다. GitHub가 독점해 온 코드 호스팅 시장에 균열이 가고 있다는 강력한 경고음이다.

진지하게 코드를 깎는 빌더들은 이제 소음 가득한 대형 광장을 떠나, 신뢰할 수 있는 진짜 동료들만의 작업실을 찾아 떠나고 있다. 깃허브가 정신 차리지 않으면, 1299번 유저의 뒤를 따르는 발걸음은 멈추지 않을 거다.
