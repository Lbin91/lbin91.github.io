DeepSeek V4 Flash가 API 기반 코딩 벤치마크에서 Grok 대비 1/10 가격으로 동일 점수를 기록한 사실이 r/DeepSeek에서 110업보트를 받았다. 같은 기간 r/LocalLLaMA에서는 Qwen 3.6 35B의 양자화 전략에 대한 실용적 논의가 262업보트와 80개 댓글을 모았다. 두 흐름은 "모델 선택의 기준이 벤치마크 점수에서 가성비와 로컬 최적화로 이동하고 있다"는 공통 방향을 가리킨다.

## API 모델의 가성비 경쟁

V4 Flash의 가격 효율성에 대한 반응은 압도적이었지만, 회의론도 있었다. 한 사용자는 "코딩은 훌륭하지만 환각율이 96%라는 점을 간과하고 있다"며 단일 벤치마크의 한계를 지적했다. r/DeepSeek의 다른 스레드에서는 "DeepSeek가 코딩에서 압도적으로 좋아졌다"는 평가가 173업보트를 받았다. 특히 코드 설명이 아닌 완전한 코드를 제공하는 능력이 실무에서 유의미하다는 평가다.

## 로컬 모델의 실전 튜닝

Qwen 3.6 35B(A3B)는 VRAM이 제한된 환경에서도 더 큰 양자화 모델이 작은 모델보다 나을 수 있다는 실용적 발견이 화제다. 8GB VRAM 환경에서 Q4 대신 Q6를 사용하는 것이 속도 저하 없이 품질 향상을 가져온다는 경험담이 공유됐다. 24GB RTX 5090 랩탑에서 Qwen 3.6 27B를 85~100 t/s로 구동하는 레시피도 등장했다.

## 시사점

모델 선택이 단순히 "가장 높은 점수"에서 "목적과 환경에 맞는 조합"으로 진화하고 있다. API 사용자에게는 DeepSeek V4 Flash가 가성비 선택지로 부상했고, 로컬 사용자에게는 Qwen 3.6의 다양한 양자화 옵션이 하드웨어 제약 내 최적화를 가능하게 한다. 중요한 것은 단일 벤치마크가 아닌 실제 사용 환경에서의 검증이다. 환각율, 응답 속도, 컨텍스트 처리 능력 등 종합적 평가가 뒤따라야 한다.
