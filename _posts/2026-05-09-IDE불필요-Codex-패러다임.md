r/codex에서 "IDE를 쓸 이유가 더 이상 없다"는 글이 232업보트, 160개 댓글을 기록했다. "Codex 앱이 GOAT다"로 시작하는 짧은 글이지만, 개발 도구의 근본적 변화를 시사한다.

## 실제로 무슨이 변하고 있나

작성자는 IDE 없이 Codex 앱만으로 코딩한다고 밝혔다. 댓글에서도 "유일하게 VS Code를 여는 이유는 git diff 화면을 보기 위해서뿐"이라는 반응이 대표적이다. 코드를 직접 작성하지 않으니 편집기가 필요 없어지는 것이다.

Codex 앱에 새로 추가된 /goal 명령어도 주목받았다(79↑, 60💬). CLI에서 먼저 공개됐다가 앱으로 확대된 기능으로, 에이전트에게 장기 목표를 설정해 두면 자율적으로 작업을 분해·실행한다.

## GPT-5.5, 추론 등급별 실제 차이

GPT-5.5의 low/medium/high/xhigh 4단계 추론 설정을 동일한 26개 실제 과제에서 비교한 결과가 공개됐다(102↑, 20💬). low와 medium은 상당히 약했고, high 이상에서 실용적 결과가 나왔다. "5.5는 추가 비용을 정당화하지 못한다, 5.4-high가 더 낫다"는 댓글이 눈에 띄었다.

## Claude Code 허니문 끝?

"허니문이 끝나가는 느낌"이라는 글이 33업보트, 36개 댓글을 받았다. "3월이 허니문의 절정이었다. 모든 개발자가 Claude Code에 뛰어들었지만, 지금은 안정성과 가용성을 신뢰할 수 없다"는 진단이다. "우리가 대체 무엇에 돈을 내고 있는 건가"라는 글도 28업보트, 77개 댓글을 기록했다.

## Claude Code 영상 편집 스킬

한 사용자가 Claude Code 스킬로 원본 영상 → 숏폼 변환 파이프라인을 구축했다(99↑, 7💬). Whisper 전사, 자동 컷, 자막, B-롤 삽입까지 전 과정 자동화. 코딩이 아닌 영역에서도 Claude Code의 활용이 확장되고 있다.

## "everybody calm down i got this" — 192업보트

r/ClaudeCode에서 Anthropic 직원(또는 핵심 기여자)이 한도·품질 논란 속에서 "모두 진정, 내가 처리한다"며 올린 글이 192업보트를 기록했다. 커뮤니티의 불안을 반영하는 동시에, 문제 인식이 내부에도 있다는 신호다.

## 시사점

개발자의 작업 공간이 IDE에서 에이전트 앱으로 이동하고 있다. 코드를 직접 작성하지 않으니 편집기가 필요 없어지는 구조다. Claude Code의 신뢰 하락과 Codex의 부상이 동시에 일어나며, 허니문 이후의 현실적 평가 단계에 접어든 것으로 보인다.
