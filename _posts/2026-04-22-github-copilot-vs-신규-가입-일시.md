서버가 터져 나가자 빅테크들의 민낯과 속내가 그대로 드러났다.

폭발하는 트래픽에 GPU 인프라가 비명을 지르는 상황에서, GitHub Copilot은 아예 문을 걸어 잠그고 신규 가입을 막았고, Claude Code와 Codex는 기존 유저들의 응답 속도와 토큰 쿼터를 후려쳤다. 같은 병목을 만났는데 대응 방식은 완전히 딴판이다.

## 무슨 일이 벌어지고 있나

GitHub가 Copilot의 신규 유료 구독을 일시적으로 전면 중단했다. 서비스 안정성을 확보하고 기존 유저들의 사용 경험을 지키겠다는 이유다.

반면 Anthropic은 Claude Code의 사용량을 쥐어짜는 쪽을 택했다. 응답 지연 시간을 슬그머니 늘리고, 한 번에 처리할 수 있는 쿼터 총량을 깎아냈다. OpenAI의 Codex 역시 비슷한 스로틀링(Throttling)을 걸어 속도를 늦췄다.

똑같은 인프라 부족 사태를 대하는 세 회사의 철학이 극명하게 갈리는 순간이다.

## 기업의 철학이 드러나는 대응 방식

**Copilot의 "신규 가입 중단"**은 기존 고객을 챙기는 가장 보수적이고 클래식한 방법이다. 새 손님을 안 받으니 서버 부하가 더 이상 치솟지 않는다. 단점은 당장 발등에 불 떨어진 신규 유저들을 경쟁사 품으로 떠밀어 버린다는 거다.

**Claude Code와 Codex의 "전체 스로틀링"**은 문은 열어두되 1인당 배급량을 줄이는 방식이다. 겉보기엔 모두에게 공평해 보이지만, 복잡한 작업을 돌리던 파워 유저들에겐 체감 품질이 곤두박질치는 최악의 경험을 준다.

커뮤니티 반응도 극명하게 갈렸다. "기존 유저 배려해서 가입 막는 게 낫다"는 옹호론도 있었지만, "어뷰징하는 리셀러 계정부터 색출해서 밴 때리는 게 먼저 아니냐"는 분통도 쏟아졌다.

## 수요 폭발의 뒷배경

이 사태가 하루아침에 터진 건 아니다. 지난 몇 달 사이 AI 코딩 도구의 침투 속도는 상상을 초월했다.

- Claude Code는 터미널 개발자들 사이에서 사실상의 표준으로 굳어졌다.
- Codex는 OpenAI의 막강한 브랜드 파워로 지분을 빠르게 갉아먹고 있다.
- Copilot은 GitHub 생태계의 든든한 둥지 위에서 여전히 가장 거대한 사용자 풀을 쥐고 있다.

결국 세 놈 다 "컴퓨팅 파워가 턱없이 모자라다"는 똑같은 벽에 부딪혔다. LLM 추론에 들어가는 GPU 자원은 살벌한데, 유저 유입 속도가 인프라 증설 속도를 아득히 추월해 버렸다.

## 로컬 LLM이 대안으로 떠오르는 이유

클라우드 도구들이 이 꼴이 나다 보니, 로컬 모델을 백업이나 메인 대안으로 올리려는 움직임이 급물살을 타고 있다.

16GB VRAM 언저리에서 매끄럽게 돌아가는 Qwen3.6-35B-A3B 같은 모델이 각광받는 이유가 바로 여기에 있다. Ollama로 로컬에 띄워두면 API 레이트 리밋도 없고, 트래픽 폭주로 인한 버벅임도 없다. 물론 순수 지능이야 Opus나 GPT-4에 못 미치지만, "언제 터질지 모르는 클라우드보다 느려도 확실히 돌아가는 내 컴퓨터"가 훨씬 믿음직하다는 거다.

오픈소스 에이전트 OpenClaw도 연일 화제다. 일일 다운로드 수십만 건을 찍으며 대세로 떠올랐지만, 잦은 버전 파편화와 만만치 않은 세팅 난이도로 여전히 삽질하는 유저들이 많긴 하다.

## CLAUDE.md 한 줄 팁의 유행

이 와중에 재밌는 프롬프트 팁 하나가 큰 호응을 얻었다. `CLAUDE.md`에 "쓸데없이 아첨하지 말고, 과감하고 솔직하게 직언하라"는 한 줄을 박아 넣었더니 Claude의 작업 태도가 눈에 띄게 시원해졌다는 거다.

물론 너무 과하면 모델이 시비 거는 꼰대처럼 변한다는 경고도 붙었다. "동료처럼 대하되 직장 상사처럼 굴지 마라"는 가드레일을 덧붙이라는 현실적인 조언이 뒤따랐다. 이런 프롬프트 레벨의 꼼수들이 뜨거운 공감을 얻는다는 것 자체가, 공식 해결책이 없는 상황에서 개발자들이 어떻게든 각자도생하고 있다는 씁쓸한 방증이다.

## 정리

AI 코딩 도구 시장이 거대한 수요와 공급의 충돌 지점에 도달했다.

Copilot은 "기존 고객 보호", Claude Code와 Codex는 "전체 배급제"를 택했다. 어느 쪽이 옳았는지는 시간이 증명하겠지만, 한 가지는 확실하다. 이 인프라 병목이 근본적으로 해결되기 전까지 로컬 LLM과 오픈소스 도구들의 입지는 갈수록 단단해질 거라는 사실이다.

그리고 유저들은 각 기업이 위기 앞에서 "사용자를 호구로 보는지, 파트너로 대하는지"를 아주 똑똑히 지켜보고 있다.
