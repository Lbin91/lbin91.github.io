내가 편하자고 깐 AI 코딩 툴이 내 홈 디렉토리를 몰래 털어서 경쟁사 설정 파일이랑 프롬프트 작업 일지를 회사 서버로 빼돌리고 있었다면? 상상만 해도 뒷목을 잡을 일이다(이게 트로이 목마지 코딩 툴인가). 그런데 그 일이 실제로 터져버렸다. r/ClaudeCode에 올라온 폭로 글의 주인공은 무려 Meta의 'Muse Code'다.

처음엔 "에이, 아무리 Meta라도 대놓고 그러겠어?"라며 반신반의했다(아님, 페이스북 시절 짬바를 잊었나). 그런데 독립 보안 감사 프롬프트를 돌려 패킷과 파일 접근 로그를 뜯어본 결과가 공개되자마자 온몸에 소름이 돋았다. 긁어간 데이터의 범위가 너무나 구체적이고 악의적이었기 때문이다.

## 도대체 무엇을 털어갔나

Muse Code가 내 로컬 컴퓨터에서 읽어간 파일 목록을 보면, Claude Code 유저 입장에선 욕이 안 나올 수가 없다.

- `~/.claude/CLAUDE.md`: Claude Code 쓰면서 프로젝트 컨텍스트, 코딩 컨벤션, 사내 룰셋을 꼼꼼하게 적어둔 핵심 자산이다. 팀의 개발 철학과 내부 보안 규칙이 적나라하게 담긴 문서다.
- `settings.json`: API 키는 아니라 쳐도, 내가 어떤 사내 도구를 쓰는지, 어떤 셸 권한을 열어뒀는지가 훤히 까발려진다.
- `~/.claude/projects/*.jsonl`: **진짜 재앙은 여기다.** 내가 Claude Code와 나눈 대화 세션 기록 전체다. 어떤 비즈니스 로직을 짰고, 어떤 버그와 씨름했으며, 어떤 코드를 복붙했는지가 고스란히 들어있다.

Codex 사용자라고 무사할까? 천만의 말씀이다. `~/.codex/AGENTS.md` 역시 귀신같이 털어갔다.

이 모든 민감한 데이터들이 사용자한테 "전송할까요?"라는 팝업창 한 번 안 띄우고, 백그라운드 데몬을 통해 Meta 서버로 조용히 전송되고 있었다.

## "호환성 때문인데요?"라는 뻔뻔한 방패

Meta 입장에서 변명할 레퍼토리는 뻔하다. "경쟁사 툴에서 Muse Code로 쉽게 갈아탈 수 있도록 호환성을 챙겨주려 했다"는 식이다. Claude Code에 적어둔 컨벤션을 지들이 읽어와서 매끄럽게 맞춰주려 했다는 건데, 말이야 방구야 싶다.

진짜 호환성이 목적이었다면 설치할 때 정중하게 물어봤어야 한다. "기존 Claude Code 설정을 가져올까요? [예 / 아니오]" 딱 한 줄이면 끝날 일이다. 

그런데 Muse Code는 백그라운드 데이터 전송을 기본값(Default ON)으로 박아뒀다. 심지어 어디서 끄는지 옵트아웃 경로도 꽁꽁 숨겨뒀다. 이건 실수가 아니라 명백한 의도다. 사용자 프라이버시 따위는 안중에도 없고, 경쟁사 에이전트의 프롬프트 엔지니어링 노하우와 유저 세션 데이터를 통째로 흡수하겠다는 거대한 욕심이다.

## 신뢰의 마지노선이 무너졌다

이 사건이 단순히 "Meta 툴 하나 안 쓰면 그만이지"로 넘어갈 수 없는 이유는, AI 코딩 에이전트라는 도구의 특수성 때문이다.

생각해 보자. 우리는 AI 에이전트에게 내 컴퓨터의 '모든 파일'을 열어준다. 소스코드 원본부터 환경 변수(.env), SSH 키가 든 `.ssh` 폴더, 프로젝트 설정 파일까지. 에이전트가 코드를 짜고 빌드하려면 파일 시스템 접근 권한이 필수적이니까 믿고 열어준 거다.

그런데 내 편의를 위해 쥐여준 열쇠로 안방 서랍을 열어 제끼고, 그 안의 일기장을 자기네 본사로 팩스 보내고 있었다면? 이건 도구가 아니라 명백한 스파이웨어다.

로컬에서만 읽고 소비하는 것과, 그걸 포장해서 외부 서버로 쏴 올리는 건 완전히 다른 차원의 이야기다. 만약 이딴 행태를 "개발 편의를 위한 혁신"이라며 어물쩍 넘어가 준다면, 내일은 Claude Code가 내 VS Code 히스토리를 털고, Cursor가 내 브라우저 쿠키를 긁어가지 않는다는 보장이 어디 있는가.

## 한 줄 요약

AI 코딩 툴 시장이 아무리 치열해도 지켜야 할 최소한의 상도덕이 있다. 더 똑똑한 모델, 더 빠른 코드 생성 다 좋지만, 내 컴퓨터에 빨대를 꽂는 순간 그건 도구가 아니라 악성코드다.

내 로컬 머신을 에이전트에게 개방하는 건 편리함을 위한 타협이다. 하지만 내가 열어준 문틈으로 도둑질을 해가는 꼴까지 눈감아줄 순 없다. 혹시라도 호기심에 Muse Code를 깔아뒀다면, 당장 터미널 켜서 프로세스 죽이고 삭제하자. 내 코딩 세션과 사내 보안은 소중하니까.
