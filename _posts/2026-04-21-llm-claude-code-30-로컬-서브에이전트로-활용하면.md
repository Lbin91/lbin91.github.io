토큰 비용 줄이겠다고 로컬 LLM을 서브에이전트로 부려먹는 기막힌 세팅이 나왔다.

Reddit r/claudecode에서 151점의 공감을 얻은 실험 결과가 개발자들의 눈을 번쩍 뜨이게 했다. LM Studio로 로컬 머신에 Qwen 3.6을 띄워두고, Claude Code의 서브에이전트로 부려먹는 하이브리드 워크플로우다.

핵심은 단순하다. 파일 목록 훑기, 단순 코드 추출, 감사 같은 반복 노가다를 전기세 0원의 로컬 모델에 떠넘기는 거다. 실제 벤치마크에서 단일 작업 컨텍스트 사용량이 62k 토큰에서 0.4k 토큰으로 쪼그라들었다. 무려 155배 절약이다. Claude Code의 `/ask-local` 커맨드로 로컬 Qwen 3.6에 질문을 쏘고, 정제된 알짜 결과만 Claude로 가져오는 구조다.

## 하이브리드 아키텍처의 현실적 위력

이 세팅이 폭발적인 관심을 받는 이유는 지갑 사정과 직결되기 때문이다. Claude API는 똑똑하지만 컨텍스트 창이 비대해질수록 토큰 요금이 기하급수적으로 폭발한다. 반면 집에서 돌아가는 로컬 LLM은 GPU만 장만해두면 호출 비용이 공짜다.

역할 분담을 보면 아주 직관적이다.
- 코드베이스 전체에서 TODO 주석 긁어모으기 → 로컬 모델
- 파일 디렉토리 구조 파악 및 1차 요약 → 로컬 모델
- 핵심 비즈니스 로직 설계 및 고난도 리팩토링 → Claude

이렇게 분업을 시키면 Claude의 천재적인 두뇌는 그대로 활용하면서, 밑 빠진 독처럼 새어 나가던 API 요금을 극적으로 틀어막을 수 있다.

## 커뮤니티 반응

"내 8GB VRAM 맥북으로는 눈물만 난다... 빨리 돈 벌어서 64GB 사야지"라는 자조 섞인 댓글이 많은 공감을 샀다. 30배 절약이라는 수치에 대해 갑론을박도 있었지만, 파일 탐색 같은 단순 반복 작업에선 충분히 재현 가능한 수치라는 게 중론이다.

## 왜 주목해야 하나

AI 코딩 툴을 쓰면서 비용 통제는 이제 선택이 아닌 생존 기술이다. Anthropic이 피크 타임에 토큰을 옥죄고, OpenAI마저 종량 과금을 빡빡하게 굴리는 마당에 클라우드 API에만 올인하는 건 너무 위험하다.

이런 환경에서 로컬 머신과 클라우드 API를 결합하는 하이브리드 파이프라인은 단순한 잔기술이 아니라 가장 현실적인 표준 아키텍처가 될 수밖에 없다.

## 정리

로컬 LLM과 Claude Code의 조합은 무섭게 치솟는 API 비용에 대한 가장 영리한 반격이다. Qwen 3.6급 소형 모델로도 충분한 잡일은 로컬에서 쳐내고, 진짜 머리가 필요한 순간에만 비싼 Claude를 호출하는 전략.

홈랩 맥미니나 서브 PC를 놀리고 있는 개발자라면 당장 세팅해 볼 만한 가치가 충분하다. 내 지갑은 내가 지켜야 한다.
