r/ClaudeCode에 최근 올라온 글 하나가 API 사용자들 사이에서 꽤 큰 물음을 던지고 있다. 프로덕션 앱에서 Opus 5.5를 같은 프롬프트, 같은 파라미터로 계속 호출해 왔는데, 10월 12일을 기점으로 호출당 출력 토큰이 눈에 띄게 늘었다는 것. 요금제도 바뀌지 않았고 코드도 그대로였는데 말이다.

수치가 꽤 구체적이다. 입력 대비 출력 토큰 비율이 0.69에서 1.09로 올라갔다. 60% 증가다. 주간 비용은 $86에서 $119로 뛰었다. 작성자는 이게 가격 인상 때문이 아니라는 걸 확인하려고 가능성을 하나씩 지웠다. 가격표는 그대로였고, 캐싱 히트율에도 변화가 없었고, 배치나 재시도 로직 실수 여부도 점검했다. 판단 근거로 Console 수출 데이터를 썼다는 점이 인상적인데, 추측이 아니라 청구 기준 데이터로 무게를 실으려던 모양이다.

## 재현 사례가 나오기 시작했다

혼자 겪은 일이라면 잡음으로 끝났을 것이다. 그런데 스레드에 다른 사용자의 재현이 붙었다. Claude Code Ultra의 로컬 트랜스크립트를 뜯어본 결과, 턴당 출력 토큰이 평균 170개 수준에서 1,600개 안팎으로 늘어 있었다는 것. 같은 방향인데 훨씬 큰 폭이다.

정리하면 이렇다. 모델이 같은 일을 하면서 더 많은 토큰을 뱉고 있고, 그 차이가 그대로 과금된다. 글쓴이는 지금 API 사용자 크레딧 보상을 요청하는 중이라고 한다.

## 왜 지나쳤을까

여기서 흥미로워지는 지점이 과금 구조다. 추론 모델의 숨은 thinking 토큰은 출력 토큰으로 과금되는데, 사용자 눈에는 그 내용이 보이지 않는다. 화면에 아무것도 안 보이니까, 응답이 짧아 보이는데 요금이 커졌다면 어디서 왔는지 짐작하기 어렵다. 이번 사례도 로그를 직접 뜯어봤기에 발견된 것이고, usage 로깅을 안 하던 팀은 그냥 비용이 조금 오른 것으로 넘어갔을 가능성이 크다.

그래서 당장 해볼 만한 건 의외로 단순하다. 호출할 때마다 usage를 기록하고, 입력 대비 출력 비율을 주 단위로 추적하는 것.

```python
import datetime, json

with open("usage_log.jsonl", "a") as f:
    f.write(json.dumps({
        "ts": datetime.datetime.utcnow().isoformat(),
        "model": "opus-5.5",
        "input": resp.usage.input_tokens,
        "output": resp.usage.output_tokens,
    }) + "\n")
```

몇 주만 쌓여도 "이 모델은 원래 이 비율이었다"는 기준선이 생긴다. 기준선이 있어야, 공급사 쪽에서 무언가 바뀌었을 때 청구서보다 먼저 알아챈다.

## Anthropic의 반응과 남은 물음

Anthropic 쪽에서는 "의도보다 한도를 많이 쓰게 만든 소소한 문제를 수정했다"면서 구독 한도를 리셋한 바 있다. 시기가 겹친다. 구독 사용자는 한도가 돌아오니 사실상 종결인데, 문제는 API 사용자다. 한도 리셋으로 덮이지 않는, 토큰 단위로 계산되는 비용은 그대로 남는다. "소소한 문제"라는 표현과 60%라는 수치 사이의 간극이 이 스레드에서 계속 논쟁되는 이유다.

## 왜 지금 주목할 만한가

이건 단순한 요금 불만이 아니다. LLM API 비용은 공급사가 모델 행동을 조정하면 사용자 몰래 달라질 수 있고, 그 변화는 청구서에만 흔적을 남긴다. 마침 같은 시기 Reddit에서는 좋은 오픈 웨이트 모델이 앞으로도 계속 무료로 공개될지 확신할 수 없다는 불안도 함께 떠올랐다. 모델 공급사의 비가시적 변경에 대한 신뢰가 얇아지는 흐름 속에서, 이 사례는 그 불안에 숫자 하나를 얹어준 셈이다.

## 정리

같은 프롬프트에 60% 더 낸 돈. 모델이 좋아진 탓일 수도 있고, 조정 과정의 실수였을 수도 있다. 어느 쪽이든 사용자가 할 수 있는 일은 정해져 있다. 자기 호출의 토큰 비율을 기록해 두는 것. 보이지 않는 토큰에 과금되는 시대에는 로그가 곧 영수증 검산이다. 크레딧 보상 요청이 어떻게 끝나는지, 그리고 다른 공급사들이 이런 사례에 어떻게 반응하는지 지켜볼 일이다.
